# وضعیت پیاده‌سازی

این سند به معنی تأیید آمادگی پردازش اطلاعات واقعی بیمار نیست.

## ساخته‌شده و قابل بررسی محلی

- Next.js App Router، TypeScript strict، Tailwind، اجزای پایه به الگوی shadcn، Motion و Lucide.
- صفحهٔ اصلی فارسی/انگلیسی با RTL/LTR، قلم محلی و طراحی اقتباس‌شده از تصویر مرجع.
- صفحات معرفی، شش خدمت، تماس، سیاست‌ها، مجله، رزرو، ورود، بیمار و ورود مدیر.
- ۳۴ جدول Drizzle و migration SQL؛ اطلاعات پزشکی و بانکی واقعی درج نشده است.
- اتصال واقعی Neon روی development برقرار شد؛ دو migration اجرا شدند و آزمون خواندن/نوشتن موقت و ورود با OTP توسعه موفق بود. شرح کامل در NEON-SETUP.fa.md است.
- کد OTP هش‌شده، محدودیت درخواست/تلاش، انقضا، مصرف یک‌باره، کوکی امن و TOTP مدیر.
- API رزرو با قفل تراکنشی، قید یکتایی، مبلغ و پیام‌رسان ثابت‌شده در زمان رزرو و کلید idempotency.
- API بررسی مستقل پرداخت، دسترسی خصوصی رسید S3، ثبت رویداد و outbox پیامک.
- پنل مدیر برای تعرفه، پیام‌رسان، حساب بانکی، بیماران، نقش‌ها، قالب و گزارش پیامک، زمان‌های رزرو، تعطیلی، تنظیمات، محتوای ساختاریافته، پیش‌نویس/تأیید مقاله و بررسی پرداخت.
- sitemap، hreflang، canonical، robots و CSP با nonce.
- Docker، Compose و پیکربندی Vercel.

## موانع خارجی

- سرویس پیامک، S3 خصوصی، مشخصات بانکی، تعرفه، ساعات واقعی، تصویر پزشک، مدارک و اطلاعات تماس تأیید نشده‌اند.
- کد به GitHub ارسال شده است؛ انتشار عمومی Vercel و دامنهٔ نهایی هنوز نیازمند اتصال حساب و تأیید محیط هستند.

## مواردی که هنوز کامل نیستند

- بخش‌های مدیریت تقویم، بیماران، نقش‌ها و پیامک دارای فرم و API هستند؛ گزارش‌گیری پیشرفته، تقویم بصری کامل، جست‌وجوی صفحه‌بندی‌شده و آزمون یکپارچهٔ این بخش‌ها هنوز تکمیل نشده‌اند.
- ویرایشگر مقاله فعلاً متن ساده است؛ rich text، زمان‌بندی انتشار، مدیریت رسانه و رابط تاریخچهٔ بازبینی تکمیل نشده‌اند.
- رنگ اصلی، URL لوگو، favicon روشن/تیره، Apple icon، تصویر اشتراک و عنوان SEO از تنظیمات خوانده می‌شوند؛ آپلود امن خود فایل‌ها، تنظیم فونت و پیش‌نمایش کامل تکمیل نشده‌اند.
- همهٔ بخش‌های سایت به CMS متصل نیستند؛ محتوای صفحهٔ اصلی از DB خوانده می‌شود، اما برخی متن‌ها و صفحات هنوز fallback کد هستند.
- مقاله‌ها پیش‌نویس‌های مقدماتی‌اند. منابع بعضاً قدیمی‌اند و شرط شش مقالهٔ اخیر و کامل هنوز برآورده نشده است. ترجمه‌ها تأیید نشده‌اند.
- اسکن بدافزار رسید، اجرای retention، حذف حساب، بازیابی حساب، MFA enrollment/recovery، اعلان یادآوری و بازیابی jobهای متوقف‌شده کامل نیستند.
- رزرو ظرفیت بیش از یک و همهٔ قوانین تقویم/تعطیلات/لغو/بازپرداخت هنوز نیاز به تکمیل دارند.
- OTP و نشست با DB واقعی و بدون ارسال SMS آزمایش شدند؛ رقابت رزرو، S3، تأیید و رد پرداخت، SMS failure و ویرایش پایدار محتوا همچنان به آزمون یکپارچهٔ بیشتر نیاز دارند.
- هیچ ادعای انطباق حقوقی، اقامت داده یا مجوز پزشکی نشده است. پیش از پذیرش بیمار واقعی باید بررسی و تأیید شوند.

برای نتایج آزمون اجراشده، فایل TEST-RESULTS.fa.md را ببینید.
