# نتایج واقعی آزمون — ۲۵ اکتبر ۲۰۲۶

## آزمون‌های اجراشده

| فرمان | نتیجه |
| --- | --- |
| `npm run build` | موفق؛ `Compiled successfully` و تولید مسیرهای App Router |
| `npm run lint` | موفق، بدون خطا یا هشدار |
| `npm run typecheck` | موفق؛ TypeScript strict |
| `npm test` | ۱۳ موفق، صفر ناموفق، یک skip مربوط به پایگاه داده |
| `E2E_BASE_URL=http://127.0.0.1:3001 npm run test:e2e` | `13 passed (29.5s)` با Chrome واقعی |
| `npx drizzle-kit generate` | موفق؛ ۳۴ جدول و دو فایل migration محلی |
| `npm audit --omit=dev --json` | صفر آسیب‌پذیری گزارش‌شده در وابستگی‌های اجرایی |

نمونهٔ خروجی آزمون واحد:

```text
tests 14
pass 13
fail 0
skipped 1
```

خروجی پایانی آزمون مرورگر:

```text
Running 13 tests using 2 workers
13 passed (29.5s)
```

آزمون‌های مرورگر شامل فارسی و انگلیسی، RTL/LTR در تگ html، تغییر زبان با حفظ مسیر، بازوبسته‌شدن FAQ، انتخاب مشاوره متنی/پیام‌رسان و بررسی فرم، خطای واقعی ورود هنگام نبود DB، محافظت پنل بیمار/مدیر، عدم انتشار مقالهٔ تأییدنشده، نبود کارت یا زمان جعلی، هر شش صفحهٔ خدمات در دو زبان، منوی موبایل، عرض ۳۲۰ پیکسل هر دو زبان، canonical/hreflang/sitemap، هدرهای امنیتی و حفاظت endpoint job هستند.

نمایش صفحه در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ بررسی شد. یک overflow در فارسی ۳۲۰ شناسایی و اصلاح و سپس آزمون خودکار آن موفق شد. تصویر کامل دسکتاپ و موبایل محلی تهیه شد؛ فایل‌ها به‌علت حجم و موقتی بودن در Git قرار نگرفتند. favicon تیره با HTTP 200 بررسی شد.

اولین اجرای آزمون مسیر job روی build قدیمی شکست خورد. پس از ساخت و اجرای خروجی تازه، مجموعهٔ آزمون موفق شد. مدیریت خودکار webServer در ویندوز هنگام teardown متوقف ماند؛ اجرای نهایی با سرور standalone مستقل و E2E_BASE_URL انجام شد و exit code صفر داشت.

نصب اولیه npm با ECONNRESET قطع شد و پس از retry انجام شد. ابزار tsx و Drizzle در sandbox با uv_os_get_passwd خطا دادند؛ اجرای مجاز خارج از sandbox موفق بود. این خطاهای محیطی به‌عنوان موفقیت پنهان نشده‌اند.

## آزمون‌های انجام‌نشده

آزمون اتصال و خواندن/نوشتن DB عمداً skip است؛ TEST_DATABASE_URL در اختیار نیست. هیچ ادعایی دربارهٔ موفقیت اتصال واقعی Neon، OTP واقعی، رقابت تراکنش‌های رزرو، ذخیره/بازیابی S3، پردازش واریز، SMS retry، نقش‌ها یا ماندگاری CMS نشده است. این موارد پس از اتصال محیط توسعه باید integration test شوند.

Docker build، انتشار Vercel، بازیابی backup، آزمون نفوذ، ممیزی کامل دسترس‌پذیری و سنجش Core Web Vitals انجام نشده‌اند. audit وابستگی‌های توسعه چهار مورد moderate در زنجیرهٔ ابزارهای توسعه گزارش کرد؛ گزارش صفر فقط مربوط به وابستگی‌های اجرایی است.
